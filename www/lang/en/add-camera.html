Add a camera

  1. Open cameras.yaml and copy an existing camera entry (or use the cam6 one).
  2. Give it a new id, a name and its rtsp_url, using a new password variable such as ${CAM6}. If you reuse an entry that has enabled: false, change that to true.
  3. Add a line CAM6=password to the .env file.
  4. Restart CamWall: on Windows close its window and run start.bat; on the Raspberry Pi run sudo systemctl restart camwall (or bash start.sh).

Finding the camera address and its RTSP URLs, and the right camera settings (H.264): README.md, section 1. Configure the cameras.
