CamWall – help

CamWall shows the picture from every IP camera listed in cameras.yaml on one page. It runs entirely on your own network – no cloud, no account.

Features

  • All cameras on one screen. The grid adapts to the window size; on a phone the cameras are stacked.
  • Group filters at the top (e.g. Outside / Inside), taken from the group field in cameras.yaml.
  • Status of every camera: Live, Connecting or Offline with the reason (e.g. camera unreachable, wrong password).
  • Automatic reconnect when the connection drops or the picture freezes.
  • Count of live cameras and a clock in the top bar.
  • Language versions with a switch in the top bar (e.g. PL | EN). Your choice is remembered.
  • Streams pause while the browser tab is hidden, sparing the cameras and the network.
  • Passwords stay in the .env file and never reach the browser.

Using the page

  • Double-click a camera (or press Enter) to enlarge it to the full window.
  • When enlarged: ← → switch to the previous or next camera; double-click, Esc or ✕ closes it.
  • F or the ⛶ button toggles full screen, ? opens this help, the ⓘ button shows information about the program.
  • The Add camera tile explains how to add a camera.

Running

  • Windows: double-click start.bat.
  • Raspberry Pi: bash start.sh in the cam_wall folder, or use autostart (see below).
  • Then open http://localhost:1984, or http://<computer IP>:1984 from another device on the network.
  • Keep the CamWall window open. Ctrl+C stops it.
  • After editing cameras.yaml or .env, restart CamWall.
  • Useful commands: python camwall.py --check (checks the configuration and translations), --download (downloads go2rtc), --help (help in the terminal).
  • Page texts and translations are in the www/lang folder; see www/lang/README.txt.

Access from outside home (optional)

  • Install Tailscale (tailscale.com) on the CamWall computer and on your phone or laptop, and sign in to the same account on both.
  • CamWall detects Tailscale when it starts and shows the address in its window, e.g. http://camwall-pc.….ts.net:1984. Open that address when away from home.
  • Without Tailscale CamWall works as before, on the home network only. The cameras do not need Tailscale.
  • Setting in cameras.yaml, settings section: tailscale: auto (default: use it if present), on (always, warn if it is not running) or off (never).

Installation – Windows 10/11

  1. Install Python 3 from python.org and tick “Add python.exe to PATH”.
  2. Copy the whole cam_wall folder, including the .env file.
  3. Run start.bat. The first time it installs PyYAML and offers to download go2rtc – answer Y.
  4. Allow go2rtc through Windows Firewall (private networks).

Installation – Raspberry Pi

  1. Copy the cam_wall folder to the Pi (USB stick or scp -r cam_wall user@Pi-IP:~/).
  2. In a terminal: cd ~/cam_wall, then bash start.sh. It installs python3-yaml and downloads go2rtc for the Pi – answer Y.
  3. Start automatically on boot: bash install-service.sh
    logs: journalctl -u camwall -f
    restart after config changes: sudo systemctl restart camwall
    remove autostart: bash install-service.sh --remove
  4. Camera wall on a monitor connected to the Pi: chromium-browser --kiosk http://localhost:1984
